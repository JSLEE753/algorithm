## 문제 정보

- 플랫폼 : 백준
- 문제 : https://www.acmicpc.net/problem/2225
- 난이도 : 골드5
- 사용 언어 : python

## 접근 방식

- `예제 입력 2`의 경우를 표로 살펴보자. 표의 각 칸들은, N을 K개의 정수로 표현하는 경우의 수를 의미한다.

- 예시)
  - `N = 0`, `K = 2` 라면, `0 + 0`의 경우인 `1`가지 경우가 존재
  - `N = 1`, `K = 2` 라면, `0 + 1`, `1 + 0`으로 `2`가지 경우가 존재

- K가 3일때까지의 경우의 수를 일일히 구하다보면, 특정 규칙이 있는 것을 눈치챌 수 있다.

- N이 `0, 1` 일 때를 제외하면, `dp[K][N] = dp[K-1][N] + dp[K][N-1]`이 성립함을 알 수 있다.

## 문제 정보

- 플랫폼 : 백준
- 문제 : https://www.acmicpc.net/problem/16234
- 난이도 : 골드4
- 사용 언어 : python

## 접근 방식

- 더 이상 인구이동이 발생하지 않을 때까지, 각 반복마다 인접한 도시들간의 인구를 재설정해야한다.

- 인접한 도시임을 확인하기 위해 bfs와 visited를 사용하고, 인구가 이동했다면 해당하는 도시들의 인구를 재설정한다. 또한, flag를 True로 지정하여 while문이 반복되도록 한다.

- 결과적으로 연합이 존재하지 않으면 while문 반복이 종료되고, 인구 이동이 발생한 n을 출력한다.

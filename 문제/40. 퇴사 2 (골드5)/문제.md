## 문제 정보

- 플랫폼 : 백준
- 문제 : https://www.acmicpc.net/problem/15486
- 난이도 : 골드5
- 사용 언어 : python

## 접근 방식

- 다이나믹 프로그래밍 문제로, N일의 날짜를 반복하며 각각의 `상담완료일`이 언제인지, `상담완료 시의 금액의 최댓값`이 얼마인지를 고려하여 풀이할 수 있다.

- 편의상 days의 [0]번째 요소에는 0,0으로 무의미한 값을 넣었고, N+1 길이의 dp배열을 생성하여 `index = 날짜`, `dp[index] = 금액` 을 저장한다.

- 상담 완료일을 계산할 때 주의할 점은, 소요시간이 1일이면 당일에 마치는 것이기 때문에, `상담 완료일 = 현재 날짜 + 소요시간 - 1` 임을 주의해야한다.

- 마찬가지로, dp[상담완료일]에 값을 작성할 때에도, 하루 전의 날짜(dp[i - 1])와 이번 날짜의 금액을 더해야 하는 것에 주의한다.
